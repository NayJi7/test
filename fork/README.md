# graphify (version locale)

Graphe de connaissances local d'un projet (code, documents, PDF, Office,
images) pour Kiro. Cette version ne contacte jamais le réseau et n'appelle
aucune IA externe : la lecture des documents et le nommage des communautés
sont faits par Kiro, via le skill `/graphify` installé par `graphify kiro install`.

- Installation : bundle interne hors ligne (voir `bundle/README.md`).
- Utilisation : `/graphify` dans Kiro, ou `graphify query "<question>"`.
- Auto-contrôle : `graphify kiro verify`.

Basé sur graphify 0.9.93 (Apache-2.0 / MIT, voir LICENSE, LICENSE-MIT,
NOTICE). Détail des modifications : `docs/MODIFICATIONS.md`.
